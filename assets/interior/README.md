# assets/interior/ – Innenraum-Assets (frei lizenziert, CC0)

Diese Dateien dürfen öffentlich im Repository liegen (CC0). Sie werden in Phase 1 noch **nicht** im Spiel verwendet;
`.gdignore` verhindert, dass Godot sie importiert und in den Web-Build packt. Beim ersten begehbaren Innenraum
die `.gdignore` entfernen.

| Ordner | Quelle | Lizenz | Inhalt |
|---|---|---|---|
| `kenney_roguelike_indoors/` | Kenney, https://kenney.nl/assets/roguelike-indoors | CC0 (`License.txt`) | 16×16-Pixel-Spritesheet (1 px Abstand): Betten, Tische, Stühle, Küche, Regale, Böden, Wände |
| `kenney_furniture_kit/isometric/` | Kenney, https://kenney.nl/assets/furniture-kit | CC0 (`License.txt`) | 120 Möbel × 4 Blickrichtungen, isometrische Renders: Bad, Küche, Schlafzimmer, Büro, Wohnzimmer |
| `opengameart_interior_16x16/` | InThePixel, https://opengameart.org/node/114339 | CC0 (`LICENSE.txt`) | kleines 16×16-Interior-Sheet |

Penzilla „Top-Down Retro Interior“ (gekauft) wird wie alle Penzilla-Dateien **nicht** hier abgelegt, sondern über
`tools/assets/import_penzilla.py` verarbeitet (keine Weitergabe im öffentlichen Repo).
